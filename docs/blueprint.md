# **App Name**: Be Fit Gym - Sangareddy

## Core Features:

- Hero Section: Display a full-screen video or high-quality image of the gym's interior to capture the user's attention immediately.
- About Section with Stats: Showcase the gym's unique value proposition with key statistics (members, trainers, transformations).
- Facilities Showcase: Display premium gym equipment and amenities in a visually appealing grid layout.
- Membership Plans: Present flexible membership options with clear pricing and compelling CTAs.
- Testimonial Carousel: Build trust through transformation stories with a smooth, auto-scrolling testimonial carousel.
- WhatsApp Chat Integration: Directly engage with potential members through a pre-filled WhatsApp message.
- Interactive Map: Display the gym's location on an interactive map, and use the AI tool to add nearby landmarks based on coordinates.

## Style Guidelines:

- Primary color: Deep red (#DC143C) to evoke feelings of strength, energy, and intensity, while still avoiding the more literal interpretation found in the prompt.
- Background color: Light gray (#E0E0E0), almost imperceptible, but sets off the black or charcoal text well
- Accent color: Light scarlet (#FA8072), which serves as a light but still distinct complement to the analogous dark red hue.
- Headline font: 'Belleza' sans-serif font to present the text in a form aligned to design
- Body font: 'Alegreya' serif font for readability
- Use consistent icons from Lucide React or React Icons to represent facilities and features.
- Subtle fade-in animations on scroll, smooth carousel transitions, and hover effects to enhance user experience without overwhelming.
